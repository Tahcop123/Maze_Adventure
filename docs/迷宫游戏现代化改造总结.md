## 四、阶段二：raylib 迁移与视觉升级

对比 raylib / SDL2 / SFML / Qt 后，选择 **raylib 5.5**：纯 C 接口、API 简洁、OpenGL 硬件加速、静态链接无运行时依赖。

### 架构改造
- 用**有限状态机**（11 个 GameState）替代原来的回调式流程；
- 新建 `maze_raylib/` 目录，与原项目并存，互不影响。

### 迁移中解决的关键兼容问题
- **去除 genlib 依赖**：Linkedlist 改为标准 C 实现；
- **raylib.h 与 windows.h 符号冲突**（`Rectangle`/`CloseWindow`/`ShowCursor`）：把 Windows 文件对话框独立到 `filedialog.c` 隔离；
- **`DrawRectangleRoundedLines` 参数差异**：raylib 5.5 只有 4 参数（无 lineWidth）；
- **光照"黑洞"问题**：`BLEND_SUBTRACT_COLORS` 只减颜色不减 alpha，无法挖洞，最终改用 RenderTexture + 加法混合方案。

### 视觉效果
从简单 2D 格子升级为：伪 3D 立体墙壁、动态光照、粒子系统、屏幕暗角。

## 六、阶段四：运行时 Bug 修复（用户实测反馈）

这一阶段的问题都由实际运行截图定位并修复：

1. **大地图全黑、小地图正常**：`Camera2D cam = {0}` 把 zoom 初始化为 0，BeginMode2D 内所有内容被缩放到不可见。修复为 `cam.zoom = 1.0f`。
2. **按一次方向键冲到路尽头**：`IsKeyDown` 每帧移动（60fps）。改为移动冷却计时器（普通 0.13s/步，冲刺 0.07s/步）。
3. **光照过曝**：经多轮调参，最终定为——黑暗遮罩 alpha=130；玩家光晕半径 2.5 格、alpha≤25、核心 0.8 格 alpha 8；钥匙 1.5 格/alpha40；终点 1.8 格/alpha45。
4. **大地图不显示迷雾**：在 DrawLighting 中遍历格子，对未探索格绘制纯黑矩形。
5. **快捷键冲突**：S 键同时绑定"保存"和"后退移动"。改为 F2 新地图 / F3 编辑 / F5 保存 / F9 打开，彻底避开 WASD。

## 七、阶段五：角色动画 + 战斗 + 第一人称

### 7.1 角色动画
`DrawPlayerAnimated`：四方向眼睛朝向、行走上下浮动（bob）、攻击挥砍特效；三种角色差异化外观（骑士蓝甲金盔 / 法师紫袍蓝帽 / 盗贼绿兜帽）。

### 7.2 战斗系统
- 空格攻击面前 1~2 格，攻击冷却 0.35s；
- 敌人 HP 血条、受伤红色闪烁；
- 击杀掉落（50% 金币 / 20% 宝石 / 10% 道具）；
- 敌人主动攻击（1s 冷却），玩家攻击力 10、含防御值与击杀计数。

### 7.3 第一人称模式（两次技术跃迁）
1. **初版 raycasting**：DDA 算法逐像素绘制，体验生硬、不会走路；
2. **平滑版**：浮点坐标 + 鼠标 look + 圆形碰撞；
3. **最终 raylib 3D**：`Camera3D` + `DrawCube`/`DrawSphere`/`DrawPlane`，GPU 硬件加速，支持自由移动、鼠标转向、头部晃动、手持武器模型。

### 7.4 精确碰撞（解决空气墙与穿模）
从"四角点检测"升级为**精确圆形 vs AABB**：
- `CircleCollides`：找到 AABB 上距圆心最近的点，比较距离平方与半径平方；
- `TryMove`：先尝试整体移动，碰撞后再分 X/Y 轴尝试，实现"沿墙滑动"而不是被卡住。

第一人称参数：眼高 0.55、碰撞半径 0.22、渲染距离 18、移速 3.0 格/秒（冲刺 ×1.6）、FOV 70°。

## 八、阶段六：三项高级渲染优化（当前最新）

全部在 `fpview.c`（348 行）内实现，编译通过并经实际运行验证。

### 8.1 程序化纹理图集（Texture Atlas）
不依赖任何外部图片，运行时用 raylib Image API 程序化生成：
- `InitTextures()`：`GenImageColor` 打底，`ImageDrawRectangle` 绘制——
  - **砖墙纹理** 128×128：水平 32px 砖缝 + 行与行交错的垂直砖缝（错缝砌筑）+ `AddNoise` 颗粒噪点；
  - **地板纹理** 128×128：32px 网格 + 噪点；
  - **天花板纹理** 64×64：素色 + 噪点；
- 通过 `GenMeshCube` + `LoadMaterialDefault` + `SetMaterialTexture(MATERIAL_MAP_DIFFUSE)` 生成带材质的立方体网格，用 `DrawMesh(mesh, material, MatrixTranslate(...))` 逐墙绘制。

> 技术注记：raylib 5.5 **没有** `DrawCubeTexture`，`DrawPlane` 也只接受 Color，因此纹理墙必须走 Mesh+Material 路线；矩阵变换函数 `MatrixTranslate` 来自 `raymath.h`。

### 8.2 Bloom 泛光后处理
经典的"亮部提取 → 降采样高斯模糊 → 加法合成"多 Pass 管线：
- 4 张渲染目标：`sceneRT`（全分辨率场景）、`brightRT`/`blurRT1`/`blurRT2`（半分辨率）；
- **brightFS**（GLSL 330）：用亮度公式 `dot(rgb, vec3(0.2126,0.7152,0.0722))`，提取亮度 > 阈值 0.55 的像素；
- **blurFS**（GLSL 330）：9-tap 高斯模糊（权重 0.227027 / 0.1945946 / 0.1216216 / 0.054054），水平、垂直各两遍共 4 个 Pass；
- 最后用 `BLEND_ADDITIVE` 把模糊光晕叠加回原始场景；
- 半分辨率模糊显著降低片元开销。

> 踩坑记录：桌面端 raylib 默认 GLSL 330（`in/out/texture()/finalColor`），不能用 GLSL 100 的 `varying/gl_FragColor/texture2D`；blur shader 的 `resolution` uniform 必须显式赋值，否则 `1.0/resolution` 除零得到 NaN。

### 8.3 视锥遮挡剔除（Frustum Culling）
`IsInViewCone(cellX, cellZ, fovDeg)`：
- 计算格子中心相对玩家的方向向量；
- 超过 `RENDER_DIST=18` 直接剔除；
- 2 格内强制渲染（避免贴脸闪烁）；
- 其余要求与视角方向的点积大于 `cos(FOV×0.6)`，即只渲染朝向视野扇形内的墙。

墙体从"遍历全图全部提交 GPU"变为"只提交视野内 + 距离内"的墙，大地图下 DrawCall 明显下降。

### 8.4 渲染管线顺序
```
BeginTextureMode(sceneRT)
  BeginMode3D
    地板/天花板平面 → 纹理墙(剔除) → 钥匙 → 终点旗 → 敌人 → 金币宝石
  EndMode3D
EndTextureMode
亮部提取 brightRT
水平模糊 → 垂直模糊 → 水平模糊 → 垂直模糊（4 Pass）
绘制 sceneRT → BLEND_ADDITIVE 叠加 blurRT2
屏幕暗角 → 准星 → 手持武器 → 操作提示
```

## 十一、已知限制与后续方向

**当前限制**
1. 第一人称 3D 场景中，`item.c` 的 4 种地面道具暂未建模渲染；
2. Bloom 阈值 0.55 偏保守，当前场景只有钥匙/金币/终点等高亮物会泛光，砖墙（亮度约 0.45）不泛光——属预期；
3. 地板/天花板仍为纯色平面（纹理已生成但未铺到地面）；
4. 墙面为无光照材质，暂未按距离做明暗衰减，纵深感主要靠暗角体现。

**可继续优化的方向**

- 手持火把/点光源：自定义 shader 传入玩家位置，照亮近处墙面并触发 Bloom；
- 地板铺设纹理网格、墙面法线贴图增强凹凸；
- 实例化渲染（DrawMeshInstanced）进一步降低 DrawCall；
- 第一人称道具建模、敌人骨骼/帧动画。

## 十二、经验小结

1. **图形库选型**优先考虑语言一致性与 API 简洁度，raylib 对纯 C 课程设计友好且能直接上 OpenGL 3D；
2. **碰撞精度**决定第一人称手感，圆形 vs AABB + 分轴滑动是解决"空气墙/穿模/卡墙"的有效方案；
3. **后处理**要分清渲染目标的分辨率、纹理上下翻转与混合模式，半分辨率是性能与效果的平衡点；
4. **着色器版本**必须匹配驱动/库的默认 GLSL，桌面端 raylib 用 330；
5. 视觉参数（光照、光晕、暗角）需在真实运行中反复对比调参，避免过曝。
